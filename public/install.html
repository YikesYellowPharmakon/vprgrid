安装与使用教程

Install & use

这份压缩包里有两样东西：extension 浏览器插件，和 app 完整应用源码。只装插件、不启动 app，打开「完整应用」就是灰屏。不需要账号，口味和参考池只存在本机。

This pack has two parts: the extension, and the full app in app. The extension alone cannot open Full app — that is the grey screen. No accounts; taste stays on this device.

02 · 开机后启动完整应用

02 · Start the full app after a reboot

完整应用在压缩包的 app 文件夹里（带 package.json）。关掉终端或重启电脑都不会自动带上。先装 Node.js LTS（nodejs.org），再任选下面一种方式。

The full app lives in the pack’s app folder (it has package.json). Closing the window or rebooting stops it. Install Node.js LTS from nodejs.org, then pick one method.

Mac 可双击解压目录里的 打开完整应用.command（或 Start-App.command）。Windows 双击 Start-App.bat。第一次会自动 npm install，要几分钟。

On a Mac, double-click 打开完整应用.command or Start-App.command. On Windows, double-click Start-App.bat. The first run runs npm install and can take a few minutes.

或打开「终端」，先进入解压出来的这个 Demo 文件夹，再进入里面的 app：

Or open Terminal, go into the unzipped Demo folder, then into app:

cd 解压后的文件夹/app
npm install
npm run dev
cd path/to/unzipped-folder/app
npm install
npm run dev
  • npm install 只在第一次做。之后每次开机只需 npm run dev。窗口不要关。
  • npm install is first run only. After that, just npm run dev. Leave the window open.
  • 终端出现 Local 后，浏览器打开 http://127.0.0.1:8080 确认不是灰屏。
  • When the terminal prints Local, open http://127.0.0.1:8080 and confirm the radar is up.
  • 插件默认找这个地址。应用开着时，新标签页点「完整应用」即可。
  • The extension looks for that address. With the app running, Full app on a new tab opens it.
  • 旧包 1.5.10 及更早没有 app 文件夹，只装插件一定会灰屏。请改用本包。
  • Packs 1.5.10 and older have no app folder. The extension alone is the grey screen. Use this pack.

03 · 连接完整应用

03 · Connect the full app

打开新标签页时，插件会自动探测本机正在跑的完整应用。应用开着，点「完整应用」就会整页进入，一般不用再手填地址。

A new tab probes the running full app. Keep the app running, then Full app opens it — you usually don’t paste a URL.

用这份 Demo 包

Using this Demo pack

  • 先按上一节把 app 跑起来，浏览器能打开 http://127.0.0.1:8080。
  • Start app as above until http://127.0.0.1:8080 loads.
  • 插件一般会自动找到它。找不到就到设置里填这个地址，保存。
  • The extension usually finds it. If not, paste that URL into Options and save.

你自己有开发项目

If you have the project folder

  • 在项目根目录打 npm run dev，窗口不要关。
  • Run npm run dev at the project root and leave it open.
  • 浏览器打开后，把地址栏复制到插件设置（默认就是上面这个地址）。
  • Copy the address bar into the extension settings if it isn’t already the default.

装好后，每个新标签页就是雷达墙：默认按月看前列专辑，可切回按周。点「完整应用」进入完整界面。

05 · 导入你自己的参考

05 · Import your reference

装上插件后，打开 RYM 收藏页或 AOTY 用户页，右下角会出现「导入到雷达」。完整应用里也可以贴网易云歌单、RSS、艺人名。

With the extension on, RYM collection pages and AOTY user pages show Import to radar. In the full app you can also paste a Netease playlist, RSS feed, or an artist name.

RateYourMusic / AOTY

先在那个网站登录，再点页面上的导入。列表会翻完所有分页，写进参考订阅。

Sign in on that site first, then hit import. It walks every page into a reference source.

同步码

Sync code

应用开着时，插件会自动跟上口味和主题。离线备份：在参考订阅里复制同步码，贴进插件设置。

While the app is running, the extension pulls taste and theme by itself. For a backup, copy the sync code from Reference and paste it into Options.

06 · 常见情况

06 · If something’s off

墙是空的或连不上

Empty wall / can’t connect

只装了插件、没启动 app，就会灰屏。确认解压目录里有 app 文件夹，按「开机后启动」跑起来，浏览器能打开 http://127.0.0.1:8080 后再点「完整应用」。若解压出来没有 app，说明是 1.5.10 那种旧包，请换 1.5.14 及更新的包。

The grey screen is the extension without the app. Confirm the unzipped folder has app, start it, open http://127.0.0.1:8080, then Full app. No app folder means an old 1.5.10 pack — use 1.5.14 or newer.

更新了文件但没变化

Updated files, nothing changed

扩展页对 VprGrid.SYS 点「重新加载」，再开一个新标签页。不要用旧的解压文件夹。

Click Reload on VprGrid.SYS, then open a fresh tab. Don’t keep an old unpacked copy.
