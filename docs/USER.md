# VprGrid.SYS · 每周新专雷达 — 使用手册

VprGrid.SYS 帮你回答一个问题:**这周有什么值得听的新专辑?** 它把两份来源合成一张周榜:

- **参考标准**:由**多个订阅源**合并而成的品味基准——内置默认参考(364 张亲选专辑)之上,可叠加任意网易云歌单、RYM / AOTY 列表、RSS 订阅、艺人追踪、粘贴清单。参考条目永远置顶、永远不会被过滤掉,参考池里的艺人在自动雷达里自动加权。
- **自动雷达**:从公开音乐目录(ListenBrainz / MusicBrainz / Bandcamp Discover)抓取的本周新发行,按你的口味自动打分排序,并自动拦掉量产流水线、白噪音等低质发行。Bandcamp 池覆盖大量只在 Bandcamp 发行的实验 / 氛围 / 即兴音乐。AOTY 新发行页启动时自动抓进扫描池(不过滤口味);RYM 新发行页服务器经常被拦——请在浏览器登录后点周导航旁的「导入 RYM / AOTY 新专」,或直接打开那些网站右下角的「导入本页新专到雷达」。

不需要注册账号,你的所有设置都保存在本机浏览器里。

## 日常启动(关掉 Cursor / 重启电脑之后)

完整应用不会随系统或 Cursor 自动起来。窗口不要关。终端出现 `Local` 后,用浏览器打开 http://127.0.0.1:8080 确认不是灰屏。插件默认找这个地址。本机需已安装 Node.js(nodejs.org 的 LTS)。

**你自己这台开发电脑:** 也可直接双击主目录里的 `快速启动.command`。或打开终端：

```bash
cd "/Users/ye/Library/Mobile Documents/com~apple~CloudDocs/Playground/NewMusic/V1"
npm run dev
```

**朋友拿到的 Demo 压缩包(1.5.14 起,里面有 `app/` 文件夹):** 先进入解压目录里的 `app`,第一次先 `npm install`,再 `npm run dev`。Mac 也可双击包里的「打开完整应用.command」。旧包 1.5.10 只有插件、没有 app,只装插件会灰屏,请换新包。

## 界面语言(中 / EN)

点顶部的**语言按钮**(地球图标,显示 EN / 中)即可在简体中文和英文之间一键切换,整套界面文案——按钮、面板、设置、提示——即时切换并记住你的选择。数据本身(专辑名、艺人名、风格标签)保持原文不翻译。

## 按周浏览

- 顶部左右箭头切换上一周 / 下一周;下拉菜单可直接跳到 2026 年任意一周;
- 「**更早收录**」是补遗桶,存放歌单里收录的 2026 年之前的发行(再版、旧作等);
- 离开当前周后,点「**回本周**」一键返回;
- 周导航旁的「**回扫补遗**」按钮:对当前停留的任意一周(包括过去的周)绕过缓存、深翻 MusicBrainz 全网发行登记(最多 6000 条,最多约一分钟),把常规抓取漏掉的冷门发行补进这一周的扫描池——翻旧周觉得池子太浅时点它;
- **艺人风格兜底**:很多高质量新专的发行页还没人打风格标签,单看发行会被漏掉。雷达会自动补一层「艺人风格」——先查艺人的整体风格档案,查不到再回翻这位艺人过往作品的标签汇总——艺人风格贴你口味的发行也会入选(入选理由标「艺人风格贴口味」,权重略低于发行本身命中)。这层档案随每次刷新和回扫逐步积累,回扫一两轮后旧周的召回会明显变宽;
- 每周页面里,标「选」的行是参考池亲选(右侧显示"亲选"),下方「自动雷达」区按综合分排序,分数越高越对你的口味。

## 听

- 每张参考亲选专辑都有 **代表曲** 按钮,点开直达网易云歌曲页;
- 行内和详情页会自动查找 Apple Music / Spotify / 网易云 / Bandcamp 的专辑链接;
- 点击任意专辑打开详情抽屉:发行信息、风格标签、打分依据、目录站跳转(MusicBrainz / Discogs / AOTY / RYM)。

## 搜索(全网,不限时间与风格)

顶部搜索框支持 **艺人 / 专辑名 / 代表曲名**,同时搜两层:

- **参考池**:全部条目跨周可搜——不管你当前停在哪一周,搜得到就能看到它属于第几周;
- **全网检索**:输入 2 个字符以上,自动并行查询 **MusicBrainz + iTunes + Deezer**(部署方配置密钥后还有 Discogs)四个公开目录,**任何年代、任何风格**的专辑 / EP 都能搜到,结果跨源去重后列在页面下方并标注来源。艺人名会做精确匹配——特殊名字(如「/f」「!!!」)也能直接列出其全部专辑。RYM / AOTY 不开放接口,搜索区提供一键直达它们站内搜索的链接。

全网检索结果右侧有「**加入参考**」按钮,点一下就把那张专辑收进你的参考体系(按发行日期归入对应周,永久置顶);自动雷达条目的详情抽屉里也有同样的按钮。手动加入的条目收在「参考设置」面板的「手动亲选」源里,可逐条移除。

## 口味定制

点「**口味 A–Z**」打开口味表:**27 个母类、350+ 子类**(按 RYM / AOTY 总风格树扩充,涵盖氛围、电声、即兴、爵士、噪音、嘻哈、金属、舞曲、全球地域、流行光谱……)按字母排列,勾选即生效。也可以自己添加母类 / 子类(标「自」),自定义的会参与自动打分。

**口味预设**(主页「参考设置」旁的芯片,口味表顶部也有):

- **Baseline**:核心实验谱系 101 子类(原始 13 母类中去掉 Rock & Post 与 Internet & Microgenre 后的 11 个母类),新用户的默认口味,一键即可回到这套核心谱系;
- **全库**:勾上全部 350+ 子类;
- 手动增减任何子类后,芯片会显示「自定义」。主页只展示已启用的母类卡片,未启用的聚合成一张「还有 N 个母类未启用」的虚线卡。

## 参考设置(品味自动调整)

点顶部的**列表图标**(或参考区块右侧的「参考设置」)打开面板。参考标准不再是单一歌单,而是一列**订阅源**,每个源可单独开关、同步、删除;添加或同步任何源都会**自动识别其中的风格并加入你的口味**,源里的艺人在自动雷达里自动加权并豁免流水线过滤——输入什么,品味就跟着什么调整。

支持的源:

- **订阅链接**(自动识别类型):
  - **网易云歌单**:全量读取曲目(上限 1000 首),同一专辑取第一首作代表曲;
  - **AOTY 用户页**:粘贴评分页 / 专辑库 / 想听链接,会自动**翻完所有分页**把全部专辑收进来,并标注参考类型;之后与 RYM 一样可点「同步」或打开时自动刷新,新评分只追加;
  - **RYM 链接(专属导入路径)**:首次导入仍走插件一键导入或粘贴 CSV。导入之后这条链接可以**直接刷新**:点源旁边的「同步」,或打开「打开时自动刷新」(默认开)。新收藏只追加进原源,不会冲掉旧清单。服务器通常会被 RYM 拦住,此时应用把任务交给浏览器插件,后台打开原链接翻页后再合并回来(需安装插件且应用在跑);
  - **RSS / Atom 订阅**(如 Bandcamp 艺人或厂牌的 feed):开启「打开时自动刷新」后,每次打开应用自动拉最新条目——适合追踪持续更新的新发行;
- **追踪艺人**:直接输入艺人名(支持「/f」这类特殊名字),全量拉取其专辑/EP 目录作参考;之后 TA 的新发行会自动高分置前、不被任何过滤规则拦下,打开应用时自动刷新;
- **添加单张专辑**:输入一条「艺人 - 专辑名 (年份)」直接进「手动亲选」,和全网检索的「加入参考」是同一个去处;
- **粘贴导入**(RYM/AOTY 兜底):粘贴 RYM 官方导出 CSV(设置 → Export your data),或每行一条「艺人 - 专辑 (年份)」;几千条、多页内容可分多次粘贴,自动去重。

源可以加任意多个(多份歌单、多条链接、多位艺人、多张专辑同时参考),面板顶部有**全选 / 全不选**,每个源卡片上还有「**仅此源**」——一键只留这一个源参与参考,适合临时对比不同参考体系。所有订阅只保存在本机浏览器;关掉「内置默认参考」的开关即可完全换成自己的参考体系,随时可再打开。

参考池除了决定「哪些艺人被加权」,还会形成一份**风格画像**:参考池里出现越频繁的风格,自动雷达里贴合它的新专辑加分越多——两个人都订「氛围」,但一个池子偏 drone、一个偏 IDM,排出来的榜单也会不同。

## 排序与过滤(右上角齿轮)

- **四个权重滑杆**:风格吻合 / 艺人水准 / 目录信号 / 封面,拖动即时重排;
- **只看口味命中**:关掉可看本周全部;
- **略过高产流水线**:拦掉短周期内量产、标题像流水编号的发行(如日更氛围专);参考亲选不受影响;
- **略过薄评分高分 / 略过粗糙封面**:剔除样本太少的高分和没有正式封面的条目;
- 专辑 / EP 可分别开关。

## AI 读封面(可选功能)

详情抽屉里的「**读封面**」让 AI 看一眼封面设计:给出 0–100 的完成度分、审美概括和两句中文点评,识别分会计入排序的封面维度。需在「AI 设置」里填齐接口;未配置时按钮会提示暂不可用,其余功能不受影响。每次会话最多识别 8 次。

## AI 艺人背景(可选功能)

详情抽屉里的「**艺人背景**」按四个维度梳理这张专辑所属艺人的公开资料:**个人作品**(代表作与年份)、**风格谱系**(源流与场景脉络)、**成就与评价**(厂牌、奖项、媒体评价)、**相似艺人 / 团体**。铁律是宁缺毋滥:AI 不确定这个名字对应哪位艺人、或某个维度查不到可靠资料时,该维度直接留空,不会编造。结果缓存在本机,同一艺人不重复消耗;需在「AI 设置」里填齐接口。

## AI 口味画像(可选功能)

「口味 A–Z」表顶部的「**AI 口味画像**」卡片,点「生成画像」后 AI 会通读你的参考池(高频艺人 + 全池均匀采样的 120 张专辑)和当前勾选的风格,产出四样东西:

- **取向画像**:2–3 句话点出你的审美坐标(场景 / 年代 / 质感 / 态度);
- **审美关键词**:最多 8 个;
- **建议开启 / 关闭的子类**:AI 只能从真实存在的风格库里挑,配「一键应用建议」按钮直接改口味;
- **值得追踪的艺人**:与参考池气质相近、仍活跃的名字,可去「参考设置 → 追踪艺人」逐个订阅。

同样宁缺毋滥:AI 没把握的维度会留空。需在「AI 设置」里填齐你自己的接口(见下)。

## AI 设置(自带密钥)

右上角的 ✦ 图标打开「**AI 设置**」:填齐你自己的 API 密钥、服务地址和模型名后,读封面 / 艺人背景 / AI 口味画像会走你的接口。需兼容 OpenAI 的 `/chat/completions`。「测试连接」可验证三件套;「清除配置」只清掉本机填写,没有内置默认服务。

密钥只保存在你自己的浏览器里(本机 localStorage),调用时经由本应用的服务端转发给你填的 AI 服务,不存数据库、不发给第三方;换浏览器或清空站点数据后需要重填。

## 界面风格

右上角调色板图标,一键切换 11 款皮肤:**Matrix(默认)/ Cyber Neon / Grainy Blur / Red Alert / Y2K Futurism / Utopian Virtual / Metalheart / Liminal Space / Frutiger Aero / Indie Kid / 自定义**。换肤只改配色、字体和质感,操作方式完全不变,选择会记住。每款皮肤的背景都是**活的**、元素多样:Matrix 的**电影式数字雨**(canvas 逐帧绘制:亮头下坠、尾迹渐隐、字符实时变异,没有固定贴图)与磷光扫描带、Cyber Neon 的霓虹夜城(三色光团游移、探照灯扫掠、楼宇灯窗与星点闪烁)、Grainy Blur 的六团弥散光斑呼吸与柔光束、Red Alert 的苏式指挥室(战术网格 + 目标框准星、雷达光束旋转扫掠、警报灯呼吸频闪、双列数据刻度流动)、Y2K Futurism 的铬光泡上浮 + 虹彩流光 + 轨道环与 HUD 十字标(低调的千禧未来主义,Blade Runner 式琥珀余温)、Utopian Virtual 的水色晨光虹掠与极简几何上浮(静谧的虚拟乌托邦渲染图)、Metalheart 的铬光斜扫与线框心形 / 星芒漂移(千禧冷铬)、Liminal Space 的日光横移与浮尘微粒(空场走廊的暖白)、Frutiger Aero 的气泡上浮与玻璃流光、Indie Kid 的涂鸦漂移——动画只垫在内容之下,不影响阅读;系统开启「减少动态效果」时自动静止。

**自定义调色**:面板底部可自选底色 / 文字色 / 强调色(其余层次自动推导),粘贴一张图片链接作全屏背景(自动加暗色遮罩保证可读),再从「无纹理 / 颗粒 / 网格 / 光晕」里选一种材质。改动任意一项即切到「自定义」主题并立刻生效,设置保存在本机。

## 收藏与删除

- 每行右侧书签图标收藏,顶部「收藏」页签集中查看(参考亲选收藏跨周可见);
- 每行(以及网格封面右上角悬停时)有**眼睛划掉图标**,点一下就把这张专辑从结果里删掉,弹出的提示里可「撤销」;详情抽屉里也有同样的隐藏开关。参考亲选不可删除。

## 导出与安装到本机

点「**下载到 Mac**」:

- **安装为本机应用**:Chrome / Edge 地址栏右侧安装图标,或 Safari「文件 → 添加到程序坞」,之后像本地软件一样从 Dock 启动;
- **离线 HTML / JSON / CSV**:把本周清单存到本机随时翻看;
- **日历提醒**:导入后系统日历每周五提醒你打开雷达。

手机浏览器同样可用(界面自适应),也支持「添加到主屏幕」。

## 浏览器插件(新标签页雷达墙 + RYM/AOTY 一键导入)

项目自带一个 Chromium 插件(`extension/` 文件夹,Chrome / Edge / Arc 通用):

- **新标签页**:顶部是**随主题变色的 Google 标志**(六个字母用当前皮肤的强调色调和上色,点击直达 Google)与 **Google 搜索框**(回车即搜),专辑墙在其下的**毛玻璃大框**里——**堆叠滑动墙**:所有封面以大弧度圆角互相叠压成一条胶片,框内**左右滑动**浏览,悬停时该张浮起到最上层并显示艺人与专辑名,参考亲选标「选」;框内上方还有一排**小组件**:时钟与日期、当地天气(IP 粗定位,拿不到就自动隐藏)、**音乐快讯**(Pitchfork 头条,点击直达);框底部是**功能条**:状态文字 + **四个滑杆**(↔ 调墙宽、↕ 调墙高与封面大小、⇅ 调大框上下位置、⇕ 上下拉长大框,拖动即时生效、自动记住,大框始终水平居中)+ 「本周 / 刷新 / 完整应用 / 设置」快捷按钮;搜索栏宽度固定,不随大框缩放;右上角的胶囊按钮可在**专辑墙 ↔ 完整应用**之间切换,选择会记住;
- **主题跟随(带动效)**:插件内置了与应用同源的十款动效主题——**免复制直连同步**:应用运行时会把最新主题 / 口味 / 参考池自动推到直连通道,插件每次打开自动拉取,换了主题**下次打开新标签页就直接生效**;自定义主题则同步配色与静态背景图,动画一起带过去(数字雨下落、铬光泡上浮、光斑游移……);
- **中英切换**:新标签页与弹窗右上角有 **EN / 中** 胶囊按钮,一键切换插件界面语言并记住选择(与应用内的语言设置相互独立);
- **工具栏弹窗**:迷你版雷达墙,随点随看;
- **一键导入**:打开 RYM 收藏页或 AOTY 用户页,右下角出现「导入到雷达」按钮——自动翻完**所有分页**,整份列表(连同参考类型:某年评分 / 总评分 / 愿望单)一次导入应用的参考设置;
- **同步口味(免复制)**:只要应用在运行,插件打开时会自动拉取你最新的口味、参考池与主题,**无需任何操作**;「参考设置」里的「复制同步码(备份)」仍然保留——离线或应用没开时,把它粘到插件设置里同样能用(剪贴板被浏览器拒绝时,直连通道也已经推送完成,不影响)。

安装:打开 `chrome://extensions` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选 `extension/` 文件夹;然后在插件设置里填应用地址。详见 `extension/README.md`。

## 常见问题

**打开是灰屏 / 插件连不上完整应用?** 完整应用没在跑,或用的是只有插件、没有 `app/` 的旧 Demo 包(1.5.10)。换 1.5.14 及更新的包,按「日常启动」把 app 跑起来。

**为什么某周的自动雷达是空的?** 自动抓取覆盖最近约三周的 ListenBrainz 热度池,并用 MusicBrainz 按发行日期直查补全本周的零听众冷门发行;更早的周主要展示参考亲选。

**我的收藏会丢吗?** 收藏、口味、主题都存在当前浏览器的本地存储里。换浏览器或清除站点数据会重置;可以先用「下载 JSON」备份清单。

**分数是怎么来的?** 打开任意自动雷达条目,详情里逐条列出加减分原因(口味命中、艺人分量、样本人数、封面等),完全透明。
